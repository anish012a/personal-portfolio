💡 IMAGE OPTIMIZATION (Optional but Recommended)

Before uploading to web, optimize your images:

1. REDUCE FILE SIZE
   - Use online tools like TinyPNG.com
   - Target: < 500KB per image
   
2. COMPRESS QUALITY
   - Slight quality reduction = big file size savings
   - Still look professional
   
3. USE MODERN FORMATS
   - WebP format (20-30% smaller than PNG/JPG)
   - Fallback to PNG/JPG for browser compatibility

4. RESIZE IMAGES
   - Gallery images: 400x400px
   - Project images: 800x600px
   - Header/Hero: 1200x800px

❓ TROUBLESHOOTING

Problem: Images not showing
Solution: Check file paths in script.js - use forward slashes (/)
         Verify images exist in the folders
         Check browser console for errors (F12)

Problem: Lightbox not working
Solution: Make sure script.js is loaded correctly
         Check browser console for JavaScript errors
         Refresh page (Ctrl+Shift+R) to clear cache

Problem: Gallery page not showing
Solution: Verify HTML includes Gallery section
         Check navigation menu includes Gallery link
         Ensure script.js initGallery() is being called
