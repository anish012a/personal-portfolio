🎯 How to Use Your Images

1Organize Images by Category

2Add Images to Gallery in HTML

The gallery automatically loads images. To add your images, update the galleryImages array in script.js:

const galleryImages = [ 'images/portfolio/design-1.png', 'images/social-media/post-1.jpg', 'images/projects/website-1.png', // Add more image paths... ];

3Use Images in Projects Section

Replace placeholder images in the projects section:

<img src="images/projects/ecommerce.png" alt="E-Commerce Website">

🎨 Image Optimization Tips

  • 📦 File Size: Keep images under 500KB for fast loading
  • 🖼️ Format: Use WebP for best compression (fallback to JPG/PNG)
  • 📐 Dimensions: Use 400x400px for gallery items, 1200x800px for projects
  • 🎯 Alt Text: Always add descriptive alt attributes for accessibility
  • 📱 Responsive: Images automatically scale on mobile!

🌟 Gallery Features

  • ✨ Lightbox Viewer: Click any image to open in full-screen modal
