## 📋 How to Use Each Image

### For Gallery Section
Add image paths to the gallery in `script.js`:
```javascript
const galleryImages = [
    'images/portfolio/design-1.png',
    'images/social-media/post-1.jpg',
    'images/projects/website-1.png',
    // ... add all your images
];
```

### For Projects Section
Replace placeholder images in HTML:
```html
<img src="images/projects/ecommerce-website.png" alt="E-Commerce Website">
```

### For Hero/About Section
Use branded images:
```html
<img src="images/portfolio/index.jpg" alt="Portfolio Showcase" class="hero-image">
```

### For Video Section
Embed the Dashain video:
```html
<video width="100%" controls>
    <source src="images/videos/dashain-promo.mp4" type="video/mp4">
</video>
```
